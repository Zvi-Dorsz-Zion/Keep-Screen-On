# מסך דלוק

אפליקציה לאנדרואיד שמשאירה את המסך דלוק כל עוד אחת מהאפליקציות שבחרת פתוחה על המסך. ביציאה מהאפליקציה המסך חוזר להיכבות כרגיל.

## התקנה
מורידים את הקובץ `KeepScreenOn.apk` מ[המהדורה האחרונה](../../releases/latest) ומתקינים. נתמך מאנדרואיד 5.0 ומעלה.

## שימוש
1. פותחים את האפליקציה ולוחצים על "פתח את ההגדרה". במסך "גישה לנתוני שימוש" מפעילים את "מסך דלוק".
2. מסמנים ברשימה את האפליקציות הרצויות. יש חיפוש לפי שם.
3. זהו. המתג למעלה מכבה ומדליק את הכול בלחיצה.

## טוב לדעת
- לחיצה על כפתור ההפעלה מכבה את המסך כרגיל, גם כשאפליקציה שנבחרה פתוחה.
- "פתוחה" פירושו שהאפליקציה מוצגת על המסך, כולל במסך מפוצל. אפליקציה שרק רצה ברקע לא משאירה את המסך דלוק.
- כשהמסך כבוי האפליקציה לא עושה כלום, ולכן אינה מבזבזת סוללה. בזמן שהמסך נשאר דלוק הוא כמובן צורך סוללה כרגיל.
- כל עוד יש אפליקציה מסומנת, מוצגת התראה קבועה ושקטה. אנדרואיד דורש אותה כדי שהשירות יוכל לרוץ. ההתראה אומרת בגלל איזו אפליקציה המסך דלוק כרגע.
- אחרי הפעלה מחדש של המכשיר השירות חוזר לבד.
- בטלפונים שסוגרים אפליקציות ברקע באגרסיביות כדאי להחריג את "מסך דלוק" ממנגנון החיסכון.
- האפליקציה לא מתחברת לאינטרנט ולא שולחת שום מידע.

## בנייה
צריך את Android Studio (בשביל ה-Java וה-SDK) ו-Gradle 8.13.

צריך קובץ חתימה ב-`android/signing/`, שלא נמצא במאגר: `keepscreen.jks` ו-`keystore.properties` עם השדות `storePassword`, `keyAlias` ו-`keyPassword`.

בווינדוס מריצים את `בנייה.cmd`. התוצר הוא `KeepScreenOn.apk` בתיקייה הראשית.
